# plamotrack
Self-hosted Gunpla/plamo collection &amp; build tracker — Docker Compose, Kanban build pipeline, and an MCP server so you can manage it via Claude or ChatGPT.

## Your data stays yours

Export the whole collection as a zip of plain CSVs (plus a small manifest with the
export and schema versions), or pull any single table down as a spreadsheet. Import
it back to restore, merge, or move to another instance — with a full preview of
every change before anything is written, and without duplicating what's already
there.

Coming from a spreadsheet, Notion, or Baserow? Grab the starter sheet: one row per
kit, and plamotrack works out the retailers, orders, and order lines for you.

See [docs/import-export.md](docs/import-export.md).
